# BlockGaze

**Your blockchain. In plain sight.**

BlockGaze builds branded block explorers and indexes EVM blockchain data, making blocks, transactions, addresses, tokens and smart contracts searchable through an explorer and a read-only API.

For private networks, growing public chains and the historical archives they leave behind. Deployments can be hosted by BlockGaze or run on your own infrastructure, with branding and retained history matched to your network.

## Build with indexed blockchain data

Use the read-only HTTP API to retrieve indexed records beyond the explorer. The public deployments can be queried without an API key or account.

The [API documentation](https://github.com/BlockGaze/blockgaze-api-docs) includes quick-start requests, endpoint guides, Swagger links, pagination, rate limits and deployment-specific coverage. Retention and available features differ by network; internal-transaction tracing has its own coverage limits.

## Built from the experience behind FSNEX

BlockGaze grew out of rebuilding FSNEX after Fusion's public infrastructure disappeared. A community member's node backup made it possible to restore access to the chain's recovered history. That work became the foundation for an explorer adaptable to other EVM networks.

[Read the Fusion recovery case study](https://blockgaze.com/fusion-recovery-case-study) · [Learn about blockchain archives](https://blockgaze.com/blockchain-archive-explorer)
